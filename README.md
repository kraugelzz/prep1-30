# พร้อมรับมือ

แอปมือถือส่วนตัวสำหรับเตรียมพร้อมรับเหตุฉุกเฉิน (เลือกได้ 1–30 วัน ค่าเริ่มต้น 3 วัน) และกันภัยไซเบอร์
ใช้ได้แม้ไม่มีอินเทอร์เน็ต ข้อมูลทุกอย่างอยู่ในเครื่องของคุณเท่านั้น

## ติดตั้งลงมือถือ

เปิดลิงก์ของแอปด้วยมือถือ **ตอนมีเน็ต** หนึ่งครั้ง แล้ว:

- **Android (Chrome):** แตะ ⋮ มุมขวาบน → "เพิ่มลงในหน้าจอหลัก" หรือ "ติดตั้งแอป"
- **iPhone (Safari):** แตะปุ่มแชร์ ⬆ → "เพิ่มไปยังหน้าจอโฮม"

หลังจากนั้นเปิดจากไอคอนบนหน้าจอได้เลย แม้ไม่มีเน็ต

## ข้อมูลของคุณ

- เก็บในเบราว์เซอร์ของมือถือเครื่องนี้ ไม่ส่งไปที่ไหน ไม่มีบัญชี ไม่มีการเก็บสถิติ
- แอปไม่มีช่องให้กรอกรหัสผ่าน เลขบัญชี หรือเลขบัตร โดยตั้งใจ
- ถ้าล้างข้อมูลเบราว์เซอร์ ความคืบหน้าจะหาย ใช้ "ทั้งหมด → สำรองข้อมูลเป็นไฟล์" เก็บไว้

## ก่อนขึ้นเว็บ: เรื่อง origin

เว็บทุกอันใน `<บัญชี>.github.io` ใช้ origin เดียวกัน จึงอ่าน localStorage ของกันได้
(รวมถึงรายชื่อและจุดนัดพบในแอปนี้) ถ้าบัญชีนี้มีเว็บอื่นที่โหลดสคริปต์จากภายนอก
ให้ขึ้นแอปนี้ในบัญชี/องค์กรแยก หรือใช้โดเมนของตัวเอง

## สำหรับนักพัฒนา

HTML/CSS/JS ล้วน ไม่มี build step

```bash
npm test                         # unit test (Node 20+)
py -m http.server 8172           # เปิดดูที่ http://localhost:8172
```

ทดสอบหน้าจอจริง: เปิด http://localhost:8172/tests/e2e.html ใน Chrome
(ผลอยู่ในหน้า และใน `window.__e2e`) — หน้านี้ล้าง service worker ของ localhost
และสำรอง/คืนข้อมูลแอปให้เอง ทดสอบออฟไลน์ให้ปิดเซิร์ฟเวอร์แล้วรีโหลดแอป

แก้ไฟล์ใดๆ แล้วรัน `npm run stamp` เพื่ออัปเดต `VERSION` ใน `sw.js` จาก hash ของไฟล์
(`npm test` จะล้มถ้าลืม) เครื่องผู้ใช้ถึงจะได้ของใหม่
ถ้าเพิ่มไฟล์ใหม่ ให้ใส่ชื่อใน `FILES` ของ `sw.js` ด้วย
